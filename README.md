# CharaNas Bot

Telegram join-request bot (see `main.py`).

## Remotion motion graphics

An After Effects–style Remotion package lives in [`remotion/`](./remotion/):

- Dynamic zoom-in on scene changes
- Overlay text with spring keyframe physics
- Animated lower-third graphic

```bash
cd remotion && npm install && npm start
```

See [`remotion/README.md`](./remotion/README.md) for props and the `VideoUploadPlayer` upload wrapper.
