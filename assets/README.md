## `charanas_logo.png`

Exact CharaNas watermark mark used by generated topic PDFs.

Required geometry (must match the official emblem):
- thin light-grey outer circle
- four **rounded blunt** navy petals (N/E/S/W), with clear white gaps between them
- petals stay well inside the circle (not sharp tips touching the ring)
- white **eight-pointed** center star with rounded tips
- thin white halo + faint contour following the four-petal outline

Rules:
- Keep this file **pixel-identical** to the official brand logo.
- PDF generation may reduce **opacity only**; it must not recolor, redraw, or reshape the mark.
- Prefer a transparent-background PNG.

Replace with the official export anytime; restart the Question Input bot so new PDFs pick it up.
Older PDFs keep the previous watermark until regenerated.
